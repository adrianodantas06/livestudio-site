Política de Privacidade

LiveStudio · Última atualização: 7 de outubro de 2026

O LiveStudio foi concebido com abordagem local-first: dados e arquivos permanecem no computador sempre que possível. Integrações externas só utilizam dados necessários ao recurso autorizado.

1. Responsável e contato

O LiveStudio é um projeto pessoal. Para assuntos de privacidade, entre em contato pelo e-mail adrianodantas06@gmail.com.

2. Dados processados

O aplicativo pode processar configurações locais, preferências de tema, cenas, referências a arquivos de mídia e dados técnicos necessários ao funcionamento. Esses dados são destinados ao funcionamento do aplicativo e, sempre que possível, permanecem no dispositivo.

3. Integração com TikTok

Quando a conexão com TikTok estiver habilitada, o LiveStudio poderá processar dados disponibilizados pelo TikTok conforme os escopos autorizados pelo usuário, como identificadores de conta, informações básicas de perfil e tokens de autenticação necessários à sessão. O aplicativo não solicitará escopos sem necessidade funcional.

4. Autenticação e tokens

O projeto é desenhado para armazenar tokens de autenticação localmente usando mecanismos protegidos do sistema operacional quando disponíveis. Tokens não devem ser incorporados ao código-fonte nem publicados. O usuário poderá desconectar a integração e revogar permissões também pelos controles da plataforma correspondente.

5. Compartilhamento

O LiveStudio não vende dados pessoais. Dados só são enviados a serviços externos quando isso é necessário para uma integração iniciada ou autorizada pelo usuário, de acordo com os termos do respectivo serviço.

6. Músicas e mídia

Arquivos de música, vídeo, desenho e outras mídias selecionadas pelo usuário são destinados ao processamento local. Futuras integrações com serviços de mídia dependerão das APIs e regras oficiais disponíveis.

7. Retenção e exclusão

Configurações locais permanecem no dispositivo até serem removidas pelo usuário ou pela desinstalação/limpeza do aplicativo. Dados de autenticação podem permanecer até a desconexão, expiração ou revogação. Solicitações relacionadas a dados controlados diretamente pelo projeto podem ser enviadas ao e-mail de contato.

8. Segurança

O projeto adota o princípio de privilégio mínimo, evita incorporar segredos no código e busca limitar a coleta ao estritamente necessário. Nenhum sistema é completamente isento de risco, e medidas poderão ser atualizadas conforme o projeto evoluir.

9. Alterações

Esta política poderá ser atualizada para refletir mudanças técnicas, novos recursos ou requisitos de plataformas. A data de atualização será indicada nesta página.

Privacy Policy

LiveStudio · Last updated: October 7, 2026

LiveStudio is designed as a local-first desktop application. Media and settings remain on the user's computer whenever possible. External integrations process only the information required for an authorized feature.

TikTok integration

When TikTok connectivity is enabled, LiveStudio may process data provided under scopes authorized by the user, including account identifiers, basic profile information, and authentication tokens required for the session. LiveStudio will not request unnecessary scopes.

Storage and security

The project is designed to keep authentication tokens locally using operating-system-protected storage where available. Secrets are not intended to be embedded in source code or publicly exposed.

Sharing

LiveStudio does not sell personal data. Data is sent to external services only when required for a user-authorized integration and subject to that service's terms and policies.

Deletion and contact

Local settings can be removed from the device. Platform permissions can be revoked through the connected service. Privacy requests concerning data directly controlled by LiveStudio can be sent to adrianodantas06@gmail.com.
